# Dolly public roadmap

| Milestone | Goal |
|---|---|
| M0 | Repository, portable safe read-only core, 68000 build experiments, RDB discovery |
| M1 | Device I/O, ADF/HDF/RAW imaging, large-device address handling, retries and verify |
| M2 | IFF `FORM DOLY`, compression, segmentation, resume, error map |
| M3 | OFS/FFS metadata analysis and DiskDoctor read-only reports |
| M4 | Smart Clone and filesystem-aware resizing for OFS/FFS |
| M5 | GadTools and ReAction GUIs, Wizard, localization and Sheep Counter |
| M6 | DiskDoctor safe recovery, reviewed repair plans, verified repair |
| M7 | PiStorm/hybrid MBR-RDB, topology and scratch optimization |
| M8 | Polish, validation, documentation, 1.0 release |

Milestones are **planning buckets**, not promised dates. Safety, regression coverage and low-memory compatibility determine release readiness.
